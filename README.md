## 🚀 About AcoBot

**AcoBot** is an AI-powered Discord assistant that brings intelligent conversation, productivity help and community tools into your server.
It understands natural language, remembers the flow of a conversation, adapts to your server's style, and helps your moderators
keep things tidy, without ever taking control away from humans.

**Why servers love AcoBot**

| | |
|---|---|
| 🧠 **Genuinely helpful** | Answers questions, explains topics, writes and explains code, translates and summarizes. |
| 💬 **Remembers the conversation** | Follow-ups just work. Say *"make it shorter"* and it knows what *"it"* is. |
| 🎛 **Fully customizable** | Admins choose its personality, language, channels, usage limits and enabled features. |
| 🛡 **Safe by design** | The AI never bans, punishes or changes settings on its own. Humans make every decision. |
| 🔒 **Private** | Every person's chats and memories are kept separate, per server. |
| 🌍 **Multi-server** | Each server has its own independent settings and data. |

> 🛡 AcoBot is a **Discord Verified Bot**, trusted to operate in communities of any size.

## ⚡ Getting started in 60 seconds

1. **Invite** AcoBot using the link above.
2. **Say hello:** type `@AcoBot hi!` in any channel it can see.
3. **(Admins) Create an AI channel:** run `/set_ai_channel` and pick a channel. AcoBot will answer every message there, no mention needed.
4. **(Optional) Choose a personality:** run `/set_ai_personality`.
5. **Explore:** type `/` and browse AcoBot's commands, or run `/help` for the full list.

That's it. No setup files, no coding, everything happens inside Discord.

## ✨ Features

### 🧠 Intelligent conversations
- Understands natural language, including casual phrasing and typos
- Answers general knowledge, school, work, technical and creative questions
- Handles **follow-up questions** using your conversation so far
- Long conversations are **automatically condensed** so AcoBot stays coherent without losing important context
- Choose your answer length: **Normal**, **Concise** or **Detailed**

### 📚 Explain anything, at your level
Use `/explain` and pick **Beginner**, **Intermediate** or **Expert**. You get a clear explanation with a short example, tuned to how much you already know.

### 💻 Coding help
- **Generate** code in the language of your choice
- **Explain** code you paste, step by step, and point out bugs or risks
- Clean, readable code blocks. Long answers split without breaking the formatting.
- AcoBot only *writes* code. It never runs it.

### 🌐 Translation
Translate any text into any language you name, such as Spanish, Japanese, Arabic or Malayalam, with `/translate`.

### 📝 Summaries
- Paste long text and get **short bullet points plus a one-line takeaway**
- Or summarize **the last 5–50 messages in the channel** to catch up fast
- You can only summarize channels you're already allowed to read

### 🧠 Personal memory *(you're in control)*
Tell AcoBot things worth remembering, like *"I prefer Python examples"* or *"I'm learning Spanish"*, and it will use them to give better answers.

- ✅ Remembers **only what you ask it to**
- ✅ View, delete, or switch memory off at any time
- ✅ Private to you and to that one server
- ⛔ Refuses to save passwords, API keys, card numbers, e-mail addresses and phone numbers

### 🎭 Personalities
Admins can give AcoBot a voice that fits the community:

| Personality | Feels like |
|---|---|
| 😊 **Friendly** | Warm, upbeat, approachable |
| 👔 **Professional** | Polished, neutral, no slang |
| ⚡ **Concise** | Short and to the point |
| 🎓 **Teacher** | Patient, step-by-step, with examples |
| 🎨 **Creative** | Imaginative and playful |
| ✍️ **Custom** | Describe your own persona in a sentence or two |

### 🌍 Languages
Set a **server-wide reply language**, or just write to AcoBot in your own language. It understands and replies naturally.

### 🛠 Everyday server tools
Polls, personal reminders, server and member info, avatars, welcome messages and more. See [Commands](#-commands).

### 🛡 Optional moderation
Spam, repeated messages, suspicious links and your own prohibited words are flagged for your moderators to review. See [Moderation](#-moderation).

### 🎛 Total admin control
Choose where AcoBot talks, which AI commands are enabled, how often each person can use it, how long data is kept, and more. See the [Admin setup guide](#-admin-setup-guide).

## 🧭 Admin setup guide

A friendly walkthrough for getting the most out of AcoBot.

### 1️⃣ Create an AI channel
Run `/set_ai_channel` and choose a channel, such as `#ask-acobot`. AcoBot will answer every message there.
Turn on **restrict_ai** if you want AI to work **only** in those channels and nowhere else.

### 2️⃣ Pick a personality and language
Use `/set_ai_personality` to choose a style, or write a custom one, e.g. *"A cheerful pirate who loves explaining science."*
Use `/set_language` to set the default reply language.

### 3️⃣ Tune usage and retention
Run `/bot_config` to set:
- **Per-user limit:** how many AI requests each person can make per minute
- **History size:** how many recent messages AcoBot considers
- **Retention:** how many days chats and memories are kept before automatic deletion
- **Enabled commands:** a menu to switch individual AI commands on or off

### 4️⃣ Set up welcome messages *(optional)*
Run `/set_welcome_channel`, then `/set_welcome_message` to write your greeting.
Example: `Welcome {user} to {server}! You are member #{member_count} 🎉`

### 5️⃣ Turn on moderation *(optional)*
Create a private `#mod-log` channel, then run `/set_moderation enabled:True log_channel:#mod-log`. See below.

### Recommended bot permissions

| Permission | Why |
|---|---|
| View Channels, Send Messages, Send Messages in Threads | Core chat |
| Embed Links | Info cards, help, status and settings |
| Read Message History | `/summarize` on recent messages |
| Add Reactions | Polls |
| Moderate Members *(optional)* | Timeouts, only if you use moderation |

AcoBot does **not** need Administrator, and it never deletes messages.

## 🛡 Moderation

Moderation is **off by default**, and your moderators always make the final call.

### What it watches for
| | Detection |
|---|---|
| 🚨 **Spam** | Too many messages in a few seconds |
| 🔁 **Repetition** | The same message posted again and again |
| 🔗 **Suspicious links** | Link shorteners, raw IP addresses, look-alike domains, links with hidden credentials |
| 🚫 **Prohibited words** | A list your admins define |

### What happens next
1. 🚩 The message is **flagged** and posted to your mod-log channel with **Dismiss / Warn / Timeout** buttons.
2. 👀 A moderator reviews it. Choose **flag only** for fully manual review, or **flag + auto-warn** for automatic warnings.
3. ⚠️ Members who collect too many warnings in a day are **temporarily timed out** (limits are adjustable).
4. ✅ Timeouts always ask the moderator to **confirm** first.

### Fairness built in
- Moderators and admins are never flagged
- Members can **appeal** with `/appeal`, and accepted appeals stop counting toward timeouts
- Adjustable sensitivity to reduce false alarms
- A full audit trail of moderation actions
- AcoBot never deletes messages and never acts against other moderators

## 🔐 Privacy & safety

| | |
|---|---|
| 🔒 **Separate by design** | Each person's chats and memories are private to them, on each server. |
| 🗑 **You control your data** | Delete a memory, clear everything with `/clear_memory`, or switch memory off. |
| ⏳ **Automatic cleanup** | Old chats and memories are deleted after the retention period admins choose. |
| 🚪 **Clean exit** | If AcoBot is removed from a server, that server's data is deleted. |
| 🧑‍⚖️ **Humans decide** | The AI can't ban, punish or change settings. |
| 🚫 **No surprise pings** | AcoBot can never mention `@everyone` or roles. |
| 🛑 **Sensitive info stays out** | Memory refuses passwords, keys, card numbers and contact details. |
| 📜 **Transparent** | Admin changes and moderation actions are logged. |

> ⚠️ As with any AI, double-check important information. Don't share passwords or private details in chat.

## ❓ FAQ

**Do I need to use commands?**
No. Just mention `@AcoBot` and chat. Slash commands are there for extra options.

**Does AcoBot remember me?**
Within a conversation, yes. For long-term memory it only keeps what you save with `/memory add`.

**Can other people see my conversations or memories?**
No. They're private to you, per server.

**Can I delete my data?**
Yes, use `/clear_memory` any time. Admins can delete all server data from `/bot_config`.

**Will AcoBot ban or punish people on its own?**
Never. Moderation only flags messages; a human moderator decides what happens.

**AcoBot isn't replying. What should I check?**
Make sure it has **View Channel** and **Send Messages** in that channel, you mentioned it correctly, and you haven't hit the per-minute limit.
If AI is restricted to certain channels, use one of those. `/ai_status` tells you whether the AI is up.

**Slash commands don't show up.**
Newly added commands can take a little while to appear. Try restarting Discord.

**Can I limit AcoBot to one channel?**
Yes. Use `/set_ai_channel` with **restrict_ai** turned on.

**Can I change how AcoBot talks?**
Yes. Pick a personality or write your own with `/set_ai_personality`.
